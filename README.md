# Global Sales Performance & Profitability Analysis (Excel)

## Project Overview
This project provides a comprehensive analysis of global sales performance (2010-2017), identifying the most lucrative markets and products to help management make informed strategic decisions.

## Key Insights
**Total Revenue:** IDR 11.22 Billion.
**Total Profit:** IDR 3.31 Billion.
**Profit Margin:** Average of 34.93% per category.
**Top Drivers:** Clothes and Cosmetics identified as primary margin contributors.

## Tools Used
**Advanced Excel:** Data cleaning (VLOOKUP, IF Functions), Pivot Tables, and Interactive Dashboard with Slicers.

## File Descriptions
* `Sales_Analysis_Dashboard.xlsx`: The original interactive Excel file.
* `Portfolio_Documentation.pdf`: Full report including strategic recommendations.
