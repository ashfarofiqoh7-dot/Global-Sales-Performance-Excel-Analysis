# Global Sales Performance & Profitability Analysis (Excel)

## Project Overview
[cite_start]This project provides a comprehensive analysis of global sales performance (2010-2017), identifying the most lucrative markets and products to help management make informed strategic decisions[cite: 346, 351, 451].

## Key Insights
* [cite_start]**Total Revenue:** IDR 11.22 Billion[cite: 451, 456].
* [cite_start]**Total Profit:** IDR 3.31 Billion[cite: 451, 458].
* [cite_start]**Profit Margin:** Average of 34.93% per category[cite: 453, 460].
* [cite_start]**Top Drivers:** Clothes and Cosmetics identified as primary margin contributors[cite: 454, 465].

## Tools Used
* [cite_start]**Advanced Excel:** Data cleaning (VLOOKUP, IF Functions), Pivot Tables, and Interactive Dashboard with Slicers.

## File Descriptions
* `Sales_Analysis_Dashboard.xlsx`: The original interactive Excel file.
* `Portfolio_Documentation.pdf`: Full report including strategic recommendations.
